ModRules для Minecraft 1.21.11 (Fabric, клиентский мод)

Сборка без установки чего-либо:
  загрузите проект на GitHub -> вкладка Actions -> build -> Artifacts -> modrules-jar.
Или локально: JDK 21, затем  gradle build  -> build/libs/modrules-1.0.0.jar
Положите jar в папку mods вместе с Fabric API.

Логика наказаний (авто-режим по умолчанию):
  Если у пункта есть кик (например "Кик 3/3"), сначала выдаются кики:
    1-й, 2-й, 3-й нарушение -> кик (счётчик хранится в config/modrules-kicks.json)
  Когда лимит киков исчерпан -> мут или бан, как указано в пункте.
  После мута/бана счётчик обнуляется.
  Пункты без кика сразу дают мут/бан.

Команды:
  /rules                      список пунктов
  /rules 3.1                  один пункт
  /punish Nick 3.1            авто: кик, кик, кик, потом бан
  /punish Nick 3.1 авто 6h    то же, но срок бана будет 6h, когда дойдёт до бана
  /punish Nick 2.1 мут 3h     принудительно мут на 3 часа
  /punish Nick 2.2 бан        принудительно бан
  /punishreset Nick 3.1       обнулить счётчик киков

Звуковой сигнал при мате на родных (пункт 2.1):
  Мод следит за чатом. Если рядом (в пределах 4 слов) стоят слово-родственник
  (мать, отец, сестра, брат и т.д.) и мат/грубое оскорбление, играет звук
  и в чате появляется красное предупреждение.
  Ловит и замаскированный мат: латиница вместо русских букв, растянутые буквы.
  /famalert on|off   включить или выключить
  /famalert test     проверить звук
  Списки слов: FamilyAlert.java (RELATIVES, SWEAR_PREFIX)

Обновление: расширен список слов про семью (мамаша, папаша, мамка, батя, предки,
бабка, дед, сестра, брат, жена, муж, тёща, свёкр, дети и т.д.), а также добавлены
оскорбления вроде "в канаве", "с помойки", "дебил". Если сигнал срабатывает слишком
часто, уберите лишние слова из SWEAR_PREFIX в FamilyAlert.java.
